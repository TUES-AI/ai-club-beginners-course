Два списъка с по 21 числа. xs[8] и ys[8] показват къде е точка 8.

Както при weights и labels в урок 3: един и същ индекс значи една и съща точка.

Числата са от 0 до 100. x расте надясно, а y расте надолу.

  • Това е единственото необичайно нещо днес: в картините y се брои отгоре надолу. По-високо в картината значи по-малко y.
  • Покажи в демото как числата в списъка ys се сменят, когато вдигаш и сваляш ръката.

Концепция03 · Правилата

Вдигнат ли е пръстът

def is_up(ys, tip, joint):
    return ys[tip] < ys[joint]

Пръстът е вдигнат, ако върхът му е по-високо от ставата. По-високо значи по-малко y.

tip е номерът на върха, а joint е номерът на ставата.

  • Функцията връща направо сравнението, както is_even в урок 3.
  • Напиши я в демото и я пробвай с примерните ръце.

Код03 · Правилата

Колко пръста са вдигнати

def count_fingers(ys):
    tips = [8, 12, 16, 20]
    joints = [6, 10, 14, 18]
    count = 0
    for i in range(4):
        if is_up(ys, tips[i], joints[i]):
            count += 1
    return count

Два списъка с номерата на върховете и на ставите. tips[i] и joints[i] са на един и същ пръст.

За всеки от четирите пръста питаме is_up и броим.

Това е шаблонът „брояч“ от първия урок.

  • Попитай ги преди да покажеш кода: как бихме преброили вдигнатите пръсти, ако вече имаме is_up?
Твой ред03 · Намери грешката

Защо получаваме грешка?

def count_fingers(ys):
    tips = [8, 12, 16, 20]
    joints = [6, 10, 14, 18]
    count = 0
    for i in range(5):
        if is_up(ys, tips[i], joints[i]):
            count += 1
    return count
IndexError: list index out of range
Отговор: в tips има 4 числа с индекси от 0 до 3. При range(5) стигаме до tips[4], а такъв елемент няма.

Правилно: range(4) или range(len(tips)).

→ показва отговора

Код03 · Правилата

Кой е жестът

def gesture(ys):
    n = count_fingers(ys)
    if n == 0:
        return "камък"
    if n == 2:
        return "ножица"
    if n == 4:
        return "хартия"
    return "не знам"

Три функции, всяка използва предишната: is_up → count_fingers → gesture.

  • След този слайд демото вече разпознава жестовете. Пусни камерата и пробвайте.

Код04 · Играта

Кой печели

def winner(me, computer):
    if me == computer:
        return "равни"
    if me == "камък" and computer == "ножица":
        return "ти"
    if me == "ножица" and computer == "хартия":
        return "ти"
    if me == "хартия" and computer == "камък":
        return "ти"
    return "компютър"

Камъкът бие ножицата, ножицата бие хартията, хартията бие камъка.

Изброяваме трите случая, в които печелим ние. Във всички останали печели компютърът.
