Концепция01 · Функции

Какво става, когато извикаме функция

def double(x):
    return x * 2

y = double(4) + 1
print(y)

x е параметър: име за стойността, която функцията получава. return връща резултата на мястото, откъдето сме я извикали.

Стъпка по стъпка
1Python запомня double, но още не изпълнява нищо.
2Стига до double(4) и влиза във функцията с x = 4.
3return връща 8.
4double(4) се замества с 8, значи y = 8 + 1.
5Отпечатва 9.
  • Всеки клик показва една стъпка. Нека класът каже какво следва, преди да я покажеш.
  • Ключовата идея: извикването double(4) се превръща в стойност. Затова можем да пишем double(4) + 1.

Твой ред01 · print или return

Двете функции изглеждат почти еднакво. Какво ще отпечата програмата?

def a(x):
    print(x + 1)

def b(x):
    return x + 1

r1 = a(5)
r2 = b(5)
print(r1, r2)
6 — отпечатва го функцията a
None 6

a само показва числото и не връща нищо, затова r1 е None. b връща числото и то се записва в r2.

Код02 · Списъци

Функция, която връща списък

def evens(nums):
    result = []
    for x in nums:
        if x % 2 == 0:
            result.append(x)
    return result

print(evens([3, 8, 5, 12, 7]))
Изход
[8, 12]

Функцията получава списък и връща нов списък само с четните числа.

Редът е винаги един и същ: празен списък, append в цикъла, return след цикъла.

Код03 · Текст

Сума на цифрите по два начина

С % и //
def sum_digits(n):
    total = 0
    while n > 0:
        total += n % 10
        n = n // 10
    return total
С текст
def sum_digits(n):
    total = 0
    for c in str(n):
        total += int(c)
    return total

И двата начина са верни. Вторият е по-кратък, но в училище обикновено искат първия.

  • Във втория начин c е символ, например "2". Затова го превръщаме в число с int(c), преди да го съберем.

Концепция04 · Първи модел

Ябълка или круша по теглото

Имаме 12 плода. За всеки знаем теглото и дали е ябълка 🍎 или круша 🍐.

Правило: ако теглото е под даден праг, казваме ябълка, иначе круша. Въпросът е какъв праг да изберем.

  • Смени прага и виж колко плода познава правилото. Питай класа кой праг е най-добър.
  • Нито един праг не дава 12 от 12, защото теглата на ябълките и крушите се застъпват.
Код04 · Първи модел

Правилото като функция

weights = [120, 135, 142, 150, 158, 163,
           168, 171, 176, 182, 190, 205]
labels  = ["ябълка", "ябълка", "ябълка", "ябълка",
           "круша", "ябълка", "ябълка", "круша",
           "круша", "ябълка", "круша", "круша"]

def guess(weight, threshold):
    if weight < threshold:
        return "ябълка"
    return "круша"

def correct(threshold, ws, ls):
    count = 0
    for i in range(len(ws)):
        if guess(ws[i], threshold) == ls[i]:
            count += 1
    return count

guess е нашият модел: правило с един параметър, прага.

correct получава праг, списък с тегла и списък с верни отговори. Връща колко плода познава моделът.

ws[i] и ls[i] описват един и същ плод.

  • Тук се събира всичко досега: функции, списъци, индекси, брояч. Мини бавно през correct.
Твой ред04 · Първи модел

Колко плода ще познае моделът?

ИзвикванеОтговор
correct(160, weights, labels)8 от 12
correct(100, weights, labels)5 — всички са „круша“, познава само крушите
correct(300, weights, labels)7 — всички са „ябълка“, познава само ябълките

→ показва отговорите един по един

  • Първият отговор се брои от числовата линия два слайда назад. При прагове 100 и 300 моделът казва винаги едно и също.
Код04 · Първи модел

Търсене на най-добрия праг

best_t = 0
best_score = 0
for t in range(100, 250, 5):
    score = correct(t, weights, labels)
    if score > best_score:
        best_score = score
        best_t = t

print("Най-добър праг:", best_t)
print("Познава:", best_score, "от 12")
Изход
Най-добър праг: 170
Познава: 10 от 12

Пробваме прагове от 100 до 245 и пазим най-добрия. Това е шаблонът „максимум“ от първия урок.

Прагът не го избрахме ние. Програмата го намери от данните. Това се нарича обучение.
