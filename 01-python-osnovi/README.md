## Как е подредена презентацията

Всяка тема минава през един и същ цикъл:

1. **Концепция** (синьо) — теорията; преподавателят обяснява по-подробно.
2. **Код** (лилаво) — разглеждаме блок с Python код и изхода му.
3. **Твой ред** (оранжево) — въпрос „какво ще отпечата?“ или „намери грешката“. Отговорът се показва **след още едно натискане** на →.

Клавиши: **→ / клик** напред (първо показва отговорите), **←** назад, **N** бележки, **O** всички слайдове, **F** цял екран.
