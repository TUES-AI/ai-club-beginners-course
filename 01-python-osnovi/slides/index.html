08 · Цикъл while

Повтаряй, докато е вярно

countdown = 5
while countdown > 0:
    print(countdown)
    countdown -= 1
print("Старт!")
while True:
    word = input("Дума: ")
    if word == "стоп":
        break

for — знаем колко пъти.

while — не знаем; спираме при условие.

break излиза веднага от цикъла.

Ако условието никога не стане False → безкраен цикъл. В Colab: бутонът ■.
  • Демо: изтрий countdown -= 1 и покажи безкрайния цикъл, после го спри. Запомнят го завинаги.
09 · Натрупване

Започни от нула и добавяй

Сума
total = 0
for n in range(1, 101):
    total += n
print(total)   # 5050
Брояч
count = 0
for n in range(1, 101):
    if n % 7 == 0:
        count += 1
print(count)   # 14

Този шаблон решава половината задачи днес: променлива преди цикъла → промяна вътре → резултат след него.

  • История: Гаус като ученик е сметнал 1+…+100 за секунди: 50 двойки по 101 = 5050.
  • Честа грешка: total = 0 вътре в цикъла → нулира се всеки път.

11 · Всичко заедно

Мини програма: оценките на класа

grades = []
while True:
    grade = int(input("Оценка (0 за край): "))
    if grade == 0:
        break
    if grade < 2 or grade > 6:
        print("От 2 до 6!")
        continue
    grades.append(grade)

average = sum(grades) / len(grades)
print(f"Средна оценка: {average:.2f}")
if average >= 5.5:
    print("Отличен успех!")

Какво има тук?

✓ вход и int()
✓ while и break
✓ if, or
✓ списък и append
✓ sum, len
✓ f-string

continue — пропусни останалото и започни следващото завъртане.
:.2f — покажи 2 знака след запетаята.
