Код02 · Размяна на две променливи

Размяна — по два начина

1 · С трета „чаша“
a = 3
b = 7
temp = a    # пазим a
a = b
b = temp
print(a, b)   # 7 3
2 · Начинът на Python
a = 3
b = 7
a, b = b, a
print(a, b)   # 7 3

Python първо пресмята дясната страна (7, 3), после записва двете стойности наведнъж.

  • Първият начин работи на всеки език (C, C++ — по другите предмети). Вторият е специално за Python.
  • a, b = b, a ще ни трябва за Фибоначи накрая.

Концепция07 · Цикъл while

Повтаряй, докато е вярно

for — знаем колко пъти.

while — не знаем; повтаряме, докато условието е вярно.

Ако условието никога не стане False → безкраен цикъл. В Colab се спира с ■.

Концепция08 · Шаблони

Четири шаблона, които решават всичко днес

Брояч
count = 0
# в цикъла:
if ...:
    count += 1
Сума
total = 0
# в цикъла:
total += x
Максимум
best = първото
# в цикъла:
if x > best:
    best = x
Флаг
found = False
# в цикъла:
if ...:
    found = True

count += 1 е съкратено от count = count + 1. Флагът казва „намерихме ли поне веднъж?“.

Всяка задача: избери шаблон → избери цикъл (for или цифри с while) → напиши.

  • Флагът е нов за тях: true/false „знаменце“, което вдигаме, ако нещо се случи. Ще трябва за „просто число“ и „съседни нули“.

Задача 10⭐⭐⭐

Повтарящи се цифри

Въведи естествено число N. Отпечатай дали в него има цифра, която се среща повече от веднъж.

Вход1234ИзходНеВход1232ИзходДа
Подсказка: цикъл в цикъл. За всяка цифра от 0 до 9 преброй колко пъти се среща в N. Ако някоя е 2 или повече пъти → Да.
  • Важно: за всяка цифра обхождаме копие на N (temp = n), иначе след първото обхождане n става 0.
