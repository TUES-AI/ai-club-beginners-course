Защо да пишем свои

Ако един код ни трябва на няколко места, го пишем веднъж и го извикваме по име.

Като в математиката

f(x) = 2x + 1, значи f(3) = 7. Функцията получава стойност и връща резултат.

  • Аналогия: рецепта. Пишеш я веднъж, готвиш по нея много пъти с различни продукти (параметри).
Концепция01 · Функции

Как се пише функция

def sum_digits(n):
    total = 0
    while n > 0:
        total += n % 10
        n = n // 10
    return total

print(sum_digits(2026))   # 10

def започва нова функция

име, по което ще я извикваме

параметри в скобите: входните стойности

return връща резултата и излиза от функцията

Двоеточие и отстъп, както при if и for.

Самото def не изпълнява нищо. Кодът вътре се изпълнява, когато извикаме функцията: sum_digits(2026).

  • Това е задача 3 от миналия път — просто я „опаковахме“.
  • Покажи, че ако напишеш само def и пуснеш клетката, нищо не се отпечатва.
Концепция01 · Функции

print или return

С print
def square(x):
    print(x * x)

r = square(4)    # показва 16
print(r)         # None

Числото се показва на екрана, но функцията не го връща, затова r е None.

С return
def square(x):
    return x * x

r = square(4)
print(r + 1)     # 17

Функцията връща числото и можем да смятаме с него.

Ако функцията няма return, тя връща None. В задачите почти винаги ни трябва return.

  • Най-честото объркване при функциите. Аналогия: print = казваш отговора на глас; return = записваш го на лист и го подаваш на съседа.

Функция в цикъл

def is_prime(n):
    for d in range(2, n):
        if n % d == 0:
            return False    # излиза веднага
    return True

for n in range(2, 30):
    if is_prime(n):
        print(n, end=" ")

Код02 · Списъци

Функция, която връща списък

def divisors(n):
    result = []
    for d in range(1, n + 1):
        if n % d == 0:
            result.append(d)
    return result

d = divisors(12)
print(d)
print("Брой:", len(d))
Изход

Брой: 6

Концепция04 · Към AI

Ябълка или круша по теглото

Имаме 12 плода. За всеки знаем теглото и дали е ябълка 🍎 или круша 🍐.

Правило: ако теглото е под даден праг, казваме ябълка, иначе круша. Въпросът е какъв праг да изберем.

  • Интерактивно: смени прага и виж колко плода позна правилото. Питай класа кой праг е най-добър.
  • Важно: нито един праг не дава 12/12 — плодовете се застъпват. Това ще ни трябва по-късно (повече признаци: цвят, форма).
Код04 · Към AI

Правилото като функция

weights = [120, 135, 142, 150, 158, 163,
           168, 171, 176, 182, 190, 205]
labels  = ["ябълка", "ябълка", "ябълка", "ябълка",
           "круша", "ябълка", "ябълка", "круша",
           "круша", "ябълка", "круша", "круша"]

def guess(weight, threshold):
    if weight < threshold:
        return "ябълка"
    else:
        return "круша"

def correct(threshold):
    count = 0
    for i in range(len(weights)):
        if guess(weights[i], threshold) == labels[i]:
            count += 1
    return count

guess е нашият модел: правило с един параметър, прага.

correct брои колко от 12-те плода познава моделът.

weights[i] и labels[i] описват един и същ плод.

Твой ред04 · Към AI

Колко плода ще познае моделът?

ИзвикванеОтговор
correct(160)8 от 12
correct(100)5 — всички са „круша“, познава само крушите
correct(300)7 — всички са „ябълка“, познава само ябълките

→ показва отговорите един по един

  • Броят се от числовата линия на предния слайд: под прага → ябълка.
  • 100 и 300 са „глупави“ модели — винаги казват едно и също. Добрият модел трябва да ги бие.
Код04 · Към AI

Търсене на най-добрия праг

best_t = 0
best_score = 0
for t in range(100, 250, 5):
    score = correct(t)
    if score > best_score:
        best_score = score
        best_t = t

print("Най-добър праг:", best_t)
print("Познава:", best_score, "от 12")
Изход
Най-добър праг: 170
Познава: 10 от 12

Пробваме прагове от 100 до 245 и пазим най-добрия. Това е шаблонът „максимум“ от миналия урок.

Прагът не го избрахме ние. Програмата го намери от данните.

Концепция04 · Към AI

Това е машинно обучение

Данни

12 плода: тегло + верен отговор

Модел

правило с параметър: weight < праг

Обучение

търсим параметъра, който познава най-много

Проверка

пробваме на нови плодове

Моделите за снимки и текст имат милиони параметри вместо един праг, но идеята е същата: търсим параметри, с които моделът греши най-малко.

Моделът греши за 2 плода, защото само теглото не стига. Следващия път добавяме и цвета.

  • Свържи с въвеждащата лекция: „учене от примери“ с ябълки и круши.
  • Проверката на нови плодове е важна — модел, който е научил наизуст данните, може да греши на нови.
