## Как се работи с тетрадките

1. Натисни бутона **Open in Colab** — тетрадката се отваря в браузъра, без инсталация.
2. **File → Save a copy in Drive**, за да се пазят промените ти.
3. Пускай клетките с **Shift + Enter**.
